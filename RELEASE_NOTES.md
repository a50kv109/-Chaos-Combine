# Release Notes — v1.0.0

## Chaos-Combine: The Engineering OS for Methodologies

We are proud to announce the first stable release of Chaos-Combine.

### Key Features
- **Deterministic Orchestration:** Python-based `ChaosEngine` for managing research workflows.
- **Methodology Library:** 5 production-ready protocols (Reduction, Audit, Red Team, etc.).
- **Agent-First Design:** Dedicated `agent_pack` and `AGENT_USAGE` guidelines for seamless AI integration.
- **Configurable Analysis:** 5 pre-defined profiles from `minimal` to `strict`.

### What's New
- Full migration from a document archive to a structured engineering toolkit.
- Implementation of JSON schemas for all report types.
- Examples covering Architecture, Physics, and IT systems.

### Status
Version 1.0.0 is marked as **Frozen Core**. Future updates will focus on specific tool implementation and new examples.
