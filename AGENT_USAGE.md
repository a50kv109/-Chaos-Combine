# Agent Usage

## Правила взаимодействия
1. **Контекст:** Всегда указывайте путь к репозиторию Chaos-Combine.
2. **Изоляция:** Не смешивайте работу с другими проектами.
3. **Методология:** Агент должен следовать протоколам из `docs/methodology/`.
4. **Результат:** Форматировать отчеты согласно `templates/`.
