# Архитектура Chaos-Combine

## Модульная структура
Chaos-Combine спроектирован как "холодный" репозиторий методологий с возможностью подключения вычислительных модулей.

1. **Слой Методологии (Methodology Layer):** Описывает "как" проводить анализ. Полностью независим от инструментов.
2. **Слой Промптов (Prompt Layer):** Интерфейс взаимодействия с LLM-агентами, транслирующий методологии в инструкции.
3. **Слой Шаблонов (Template Layer):** Обеспечивает единообразие вывода инженерных вердиктов.
4. **Ядро (Core/Tools Layer):** (Reserved for future expansion) Автоматизированные скрипты обработки данных.

## Принципы изоляции
Проект Chaos-Combine является автономным. Использование внешних библиотек или заимствование архитектурных решений из смежных проектов (таких как AAM или ACP) допускается только на уровне универсальных инженерных паттернов.
