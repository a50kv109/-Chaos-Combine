# Основные концепции (Core Concepts)

- **Chaos (Хаос):** Неупорядоченная сложность, мешающая пониманию системы.
- **Combine (Комбайн):** Совокупность инструментов для переработки хаоса в порядок.
- **Entity (Сущность):** Минимальный неделимый элемент смысла в системе.
- **Noise (Шум):** Избыточные данные или код, не несущие полезной нагрузки.
