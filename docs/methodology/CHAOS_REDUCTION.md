# Методология: Chaos Reduction

## Назначение
Декомпозиция сложной системы до минимально необходимого набора примитивов без потери её функциональной сути.

## Область применения
- Оптимизация легаси-кода.
- Подготовка спецификаций для переписывания систем.
- Поиск архитектурных избыточностей.

## Ограничения
- Не должна приводить к потере критически важного поведения.
- Требует четкого определения границ системы перед началом.

## Workflow
1. Идентификация всех функций системы.
2. Категоризация: Ядро, Вспомогательное, Декоративное.
3. Удаление декоративных элементов.
4. Слияние вспомогательных элементов с ядром.
5. Проверка целостности.

## Формат результата
Инженерный отчет о редукции (Reduction Verdict), содержащий список удаленных сущностей и обоснование сохраненного ядра.
