# Методология: Semantic Drift Analysis

## Назначение
Обнаружение расхождений между первоначальным смыслом (Design Intent) и фактической реализацией системы.

## Workflow
1. Сбор исходных требований.
2. Анализ текущего состояния кода/документации.
3. Сопоставление и выявление "дрейфа" значений.

## Формат результата
Карта семантических расхождений.
